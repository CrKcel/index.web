# 视觉与行为基准

## 参考与实现

参考为原片的 5–40 秒，1920×1080、25fps。应用内部时间码为原片时间减 5 秒；正常启动与重播从原片 6.76 秒的白色画面开始，黑底的鹰角网络片头不纳入。美术模型通过 Blender MCP 制作，保留源文件与可复现脚本；界面使用 TypeScript、Three.js 与 Vite，开场由 DOM / SVG 与场景时间轴驱动。原片与提取帧仅用于本地对照，不作为产品背景，不随仓库分发。

- 暖灰白底、黑色文字、暖杏金选中信号。界面以细线和紧凑排字组织，保留原片标题与右下角署名位置。
- 字体为用户指定的 MiSans，采用 `misans-webfont@4.3.1`（源字体 4.003）分包，同源固定版本、按字符加载，保留 300、400、600、700 四个字重与 `font-display: swap`，后备为 PingFang SC / Microsoft YaHei / system-ui。分片字节不改动，移除上游 CSS 的 local() 以免设备字体覆盖固定版本。版权、许可与分片哈希见 `public/fonts`，设置页含署名与许可入口。
- 开场中央文字使用 Novecento Sans Wide：访问、身份、请求、处理、授权提示为 Normal，欢迎三行为 Bold，左上 RHINE LAB 为 DemiBold，其下两行保留 MiSans。授权 WOFF2 单独存放并排除公开 Git，加载失败时回退到固定轮廓图形。
- 模型由磨砂盖板、基板、内部光学腔、环槽、边框、螺钉、标签与刻线组成，圆环位于盖板后方。交互阵列以投影贴图绘制这一外观，代理取卡片的包围盒；开出与查看器仍使用带物理透射的完整几何。
- 灯光统一到 `src/archive-lighting.ts`：曝光 1.00，环境强度 0.52，暖白主光 1.7，主光位置 (-8,14,4)，补光 0.3，半球光 0.5。主场景与独立查看器各自在自己的 WebGL 上下文生成环境贴图。

## 屏幕比例与触摸适配

`src/viewport-layout.ts` 统一舞台尺寸与取景参数。启动与重播保留完整 16:9 参考舞台；桌面交互以 1080 逻辑高度延展宽度；窄屏和竖屏使用真实 CSS 像素布局，文字与按钮不整体缩小，16:9 基准仍落在原坐标。

- 横屏保持左侧模型、右侧档案。窄横屏正文独立滚动，导航适当错行；竖屏正文从屏高 54% 开始，保留上方模型、返回与 360° 入口。短屏取景额外受返回按钮与正文上沿约束。
- 模型位置与运动函数固定；通过相机锚点和垂直取景范围保证构图，竖屏预览使用固定基准焦点，不抵消抬起、呼吸和轨道运动。
- 主要操作至少 44px 触控高度，档案刻度为次要跳转目标；顶部、底部与两侧边距读取安全区域。
- 触摸在阵列区域左右切列、上下切档；详情获得净空后可单指检查，360° 查看器单指旋转、双指缩放和平移。正文滚动与场景手势隔离，旋转屏幕保留当前选档、视角与拆解状态。

## 循环档案阵列

内容编号与物理位置分离：五类档案、每列八份按周期映射到连续的行列坐标。上下、左右的方向操作每次改变一个物理位置，最后一项接续第一项时轨道继续沿原方向运动；切列保留该列的档案选择记忆。点击场景卡片使用当前实例实际对应的档案与位置。

- 五列分别为工程研究、生命科学、机构档案、能量研究、特别项目，各 8 份，共 40 份内容。
- 交互阶段每张卡片是包围盒代理加一张烘焙投影：加载时按稳定镜头的方向与镜头距离把阵列材质渲染一次，亮暗主题各存一张，所有实例共用同一份投影，片元再按同一台烘焙相机重新投影取样。代理保持卡片自身的形状与深度，抽出模型与背景卡片的遮挡关系和建模表面一致；每帧只有一次贴图绘制，不再重复走透射、深度与法线通道。开场时间轴会绕行镜头，该段仍绘制建模表面。
- 交互阵列按渲染当帧插值后的相机重新计算覆盖范围：截取视锥与阵列可占据的高度区间，换算为行列候选，再用完整卡片边界裁剪，紧凑写入实例矩阵。鼠标点击与拾取使用同一份实际实例映射。
- 默认保留 18% 的屏幕方向余量，额外档为 50%，并保留附近阴影贡献。实例缓冲按需增长并复用容量，实际绘制数独立于缓冲容量。
- 显式原片逐帧对照保留原始的前 160 个位置；正常开场与交互阶段按实际视口动态生成背景档案。
- 横向采用整组阵列轨道平移，纵向保留前后轨道，两者都保留阻尼与速度；选定后的抽取只改变高度。逻辑坐标超过 2048 时按内容周期统一平移坐标与运动状态，保持世界位置、速度、波纹与呼吸相位连续。

### 拖动与惯性

鼠标与触摸共用自由平面拖动：用当前相机的两条投影轨道还原屏幕位移，一次拖动可随时转弯或反向。按住时采样切列轨道与切档轨道的每格 CSS 位移，对两条投影向量组成的 2×2 矩阵求逆，将屏幕位移同时分解到两个轨道；取消横竖快捷手势与斜向锁轴，仅保留 10px 起拖阈值。

松手后按实际速度持续减速，快拖与慢拖产生不同滑行距离，不做固定距离上限。选档随实际轨道位置变化，临近停止才吸附；再次按住从当前画面接管。自由滑行期间两个速度分量使用相同衰减并共同吸附；减少动态效果时不继续惯性滚动。滚轮只用于列内切档。

### 选中、波浪与呼吸

- 左右切换停在浅抬起状态（0.4 世界单位），邻排沿同一肩部轮廓排列；选中与波浪同时开始，波浪保留正向波峰与负向波谷，升降阻尼速率为 4.2。
- 悬停卡片额外竖直抬起 0.28，约 200ms 显现，移开平滑回落；悬停高度独立于选中抬起与详情抽取，不改变镜头进度，所有网格部件一起移动。
- 交互预览停止操作 2.5 秒后渐入呼吸起伏：8 秒与 13 秒周期叠加，最大单向位移 0.102 世界单位，相邻卡片略微错相；切换档案、进入详情或开启减少动态效果时渐退。原片时间轴不叠加此效果。
- 列间的突出程度连续插值，非选中列保留至少 25% 的肩部波幅；镜头的转正、推进与雾效距离都跟随阻尼后的实际镜头位置。

## 抽取、解密与阅读

- 卡片超过浅抬起高度后，镜头才逐渐转向并把卡片放在画面左侧；详情文字随镜头进度在右侧渐显。交互详情升至 4.05 世界单位，原片时间轴的完整升高为 3.35。
- 抽取只允许竖直升降，靠近与转向由摄像机完成，不向前或横向平移模型；背景卡片不随特写进度额外下沉。
- 只有卡片完全避开邻片后才接受拖拽（旋转限幅 ±0.8 弧度）；收回时保持高度先转正，再下降。被换选的旧卡片遵守同一顺序，附近旧卡片转正时新预览暂缓抬起。
- 阵列与抽出模型共用外壳几何，在同一表面随升降连续插值颜色、粗糙度与透光率；内部结构以连续覆盖率显现。每张归位卡片拥有独立材质状态，接近完全归位且外观一致后才恢复阵列实例。
- 黑色解密线按 25 fps 采样重建：两端沿同一物理对角线向中央延伸、保持，再向中央收束，最后逐渐透明，使用单调三次插值无过冲。交互详情在卡片抬起和镜头就位后启动，时间压缩至约 3.63 秒；减少动态效果时直接清晰。
- 选中盖板在解密进度 0 时整面 roughness=0.48，进度 1 时为 0.025，中间羽化宽度为高度的 24%，边界自上向下移动。精选内构的磨砂采样范围限制在盖板投影高度的约 1.6%，避免小尺寸预览过度模糊。
- 详情长焦距离约 72，近裁剪面为 5、远裁剪面保持 300，避免薄层内构深度冲突；镜头位置、视场角与构图不变。
- 档案正文为基于公开世界观资料的原创编目文章，不冒充游戏内原始档案，每份包含设定参考链接，见 `reference/LORE-SOURCES.md`。

## 独立模型查看器

- 详情页的「360° 查看文档模型」打开独立场景，沿用暖灰背景、既有字体与克制的中英文字阶。
- 鼠标左键拖动环绕模型；上下左右键平移视角，滚轮或加减键缩放；Home 或「复位视角」恢复初始取景；ESC 或「返回档案」关闭。
- 「拆解档案」将紧固件、透明盖板、折射环组、光学核心、信息基板、背板与框架六组部件沿厚度轴分离，「一键重组」准确复位；途中反向保留当前运动位置与速度。减少动态效果时直接切换。
- 查看器暂停主场景绘制，复用校准后的材质、环境光配置与当前档案标签；近裁剪面 0.3，远裁剪面 120，初始相机位置 (7.2, 3.8, 12)，缩放距离 5–28。
- 进入约 320ms 淡入并轻微上移，模型载入后约 380ms 从 0.97 倍展开；退出约 220ms 淡出并轻微收拢。使用可取消的原生动画，进入中途按 Esc 从当前透明度退出；退出结束前保留模型与模态焦点，之后释放并返回原按钮。
- 清晰／磨砂切换复用主场景材质逻辑，不重置观察位置或拆解进度；退出查看器回到已解密的原档案，退回阵列时恢复磨砂。
- 部件资源由 `art/build_assembly.py` 生成，导出带 assemblyPart 信息的 `public/assets/archive-assembly.glb`，并保留 `art/archive-assembly.blend`。

## 开场动效

以原片连续帧复核 6.76–27.00 秒，`src/boot-motion.ts` 将逐字输入、停顿、清空与闪切固定到原片帧点，空间位置使用连续插值；`src/boot.ts` 驱动 DOM / SVG，正常播放、慢放与前后跳帧共用同一画面状态。

- 英文从固定左端输入，标志从右上弧线开始绘制、绕左环再补全右环，完成后向左移位；品牌三行错开出现。
- 身份段为 `ID CONFIRMED : JOYCE MOORE`、`REQUEST RECEIVED`、`START PROCESSING...`；权限段使用从画面外收拢的黑白双环、反向内弧、橙色节点、四帧缩放跳变与中心图形切换；欢迎段保留黑白闪切、公司名称黑底横向扫过与 `INTERNAL DATABASE` 闪现，最后缩小、失焦并带轻微青色过渡进入白场。
- 两侧小圆以原位旋转和弧段补全为主，左右反向旋转并减速；圆心只保留轻微收拢，中央圆点周围的六颗小点沿约 35px 轨道绕行、每隔三帧进入；中央大点闪变后缩小。
- 加号与方点同帧展开，方点随后拉成长横；Logo 左移按实测位置拟合，缺口沿轮廓移动，整个标志保持黑色，不使用整枚透明度闪烁。
- 品牌三行使用原版 MiSans 排版、与共享标志一致的路径；品牌容器左 59px、上 114px、宽 270px，第一行 44px / 48px 行高 / 2.5px 字距，第二行 19px / 23px 行高 / 600 字重 / 0.65px 字距，第三行 35px / 40px 行高，ANALYSIS 按黑色字面起点校准字距，OS 右对齐。

## 标题、编号与文字滚动

主档案标题、顶部分类、底部列名、悬停标题与权限标签复用 `@kitlangton/rolling-number` 的 `createRollingText`，与编号共享 460ms 时长；使用 direct 模式直接替换中文，固定向上滚动，轻微模糊与宽度过渡。内容相同不重复播放，悬停首次出现直接显示；连续输入从当前运动接续并显示最新目标，进入详情、重播或减少动态效果时立即落到最终文字。

档案序号与列编号使用同一组件的原生 DOM 接口，固定两位数；X-001 形式的主编号与悬停编号固定 X- 前缀、三位数字保留前导零。方向键跨循环边界时保留滚动方向；减少动态效果或页面设置可关闭滚动。许可随包保存到 `public/licenses/rolling-number.txt`。

## 详情、弹窗与页签过渡

详情层约 180ms 进出，正文跟随实际镜头进度显示；阵列氛围与右侧浅色遮罩按同一镜头进度交叉渐变，快速反向从当前透明度接续，进入正文的焦点等待可读状态。检索、收藏和设置弹窗约 300ms 入场、200ms 退出，面板入场位移 12px、退出位移 8px；退出期间保留节点与背景输入隔离，结束后恢复焦点，再执行选档或重播。页签正文 150ms 淡入，下划线 180ms 连续移动；收藏仅修改按钮、计数与 220ms 颜色反馈，保留正文节点、页签及滚动位置。减少动态效果时直接切换。

## 音效与配乐

原片 6.76–40 秒画面及音轨动态、莱茵生命相关设定为参考，配乐为原创「观测室」三轨循环，交互音效区分玻璃碰触与系统操作。浏览、详情、独立模型查看以及启动阶段采用不同声部比例，用户可以独立控制音乐与音效，旧版静音偏好继续生效。

- 玻璃交互使用短起音、不等间隔共鸣与迅速衰减的高频，区分切档轻碰、抽取余音与归位落定。
- 逐字输入使用原片约 6.864–6.986 秒的三个 38ms 短音轮替，保留源波形，按实际文字揭示帧触发，输入最短间隔 24ms；新字段首字有反馈，闪动恢复不误触发。
- 窗口开合使用短电子升降音，启动标志使用低频缓起和声，整块文字显现使用轻微数据脉冲，授权使用双电子短音。
- 配乐生成器为 `scripts/render-audio.mjs`，音效合成为 `src/audio.ts`，来源与处理记录见 `public/audio/README.md`。

## 画质与性能

设置提供性能、原始、高、极高四个预设及九项独立参数：渲染比例、像素密度上限、SMAA 抗锯齿、纹理过滤、透明材质分辨率、阴影分辨率、环境遮蔽采样与分辨率、景深强度。默认采用原始预设，画质仅调整渲染精度与可选效果，不重新制作模型。清晰度与材质参数同步至 360° 查看器；阴影、AO 和景深仅用于阵列。面板显示实际渲染尺寸与硬件限制后的纹理倍率，全尺寸缓冲上限为 8,294,400 像素，渲染比例最高 200%。

## 明暗配色

暗色以 #11181b 为背景，#e0e3dc 为正文，#a6b0b1 为辅助文字，#536166 为分隔线，#c5a16b 为琥珀强调，保留原版排版与布局，不使用全屏反色。三维阵列使用独立的烟灰材质端点与冷灰边缘；清晰盖板随自上而下的解密前沿恢复接近无色的透射。切换以选中单元为起点：每行延迟 34ms、每列 110ms，最远延迟 600ms，单卡过渡 580ms，背景 850ms；不附加升降或位移，快速反向接续各卡当前颜色，减少动态效果直接应用目标配色。暗色雾颜色为 #263136，预览雾起点为相机至目标距离加 1、终点加 16，浅色仍为加 5／加 25；详情过渡为加 −1／加 12。

## 主屏幕与离线

正式域名为 https://index.crkcel.com/，部署在 Cloudflare Workers。PWA 使用 standalone 窗口、浅暖色主题与共享莱茵生命图标，iPhone 使用 180px Apple Touch Icon，其他设备提供 192 / 512px 与 maskable 图标，状态栏、底部手势与横屏刘海通过安全区域留白处理。

首次联网准备完整资源（约 34 MiB，包含字体、模型、声音和 40 份档案），HTML 与资源使用同一内容版本；下载成功后新版本进入等待状态，用户选择“更新并重启”后应用。下载失败保留完整旧版本，收藏和偏好不随资源更新清除。设置图标下方保留“设置”文字，新版就绪时在底部状态区提供直接更新入口；`update.html` 提供网络恢复入口。见 `docs/PWA.md`。

## 动效偏好

动效支持完整／减少／自定义及分组开关，首次访问跟随系统“减少动态效果”偏好，之后以本站保存的设置优先。关闭模型解密动效时详情直接清晰、阵列及归位副本恢复磨砂，正文揭示仍独立控制；主题与各项动效共存。
